Wi-FiWebsites

> websites to watch_

Choose which websites the screen keeps an eye on. Come back any time to change them.

This page needs Google Chrome or Microsoft Edge on a computer (Windows, Mac, Linux or ChromeOS). Safari, Firefox and phones can't talk to USB devices.

1. Connect the board

  1. Plug the board into this computer with the USB-C cable.
  2. Click Connect and pick the device in the list (usually "USB JTAG/serial debug unit" or "ESP32-S3").

2. Websites

One per line, up to 16. Lines starting with # are ignored.

The screen has room for 5. All websites on the list are checked, but only 5 are shown at once, and anything with a problem always moves to the top. So with more than 5, the extra ones stay hidden while they're fine and pop up as soon as they go down. The bottom of the screen shows +2 more when some are hidden.

statuspage | Name | https://status.example.com — the company's own status page
http | Name | https://example.com — is the site up? (any 2xx/3xx is fine)
http | Name | https://example.com/health | 200 — require an exact status code

No cable handy? Once the board is on Wi-Fi, you can also edit this list from any phone or computer on the same network at http://service-monitor.local/, or at the IP address shown on the board's second screen (press the left button).
